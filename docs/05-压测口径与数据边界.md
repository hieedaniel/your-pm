# 内部口径说明

标称 **10 万点/秒** 来自 **3 节点集群**压测（时序写入走批量追加 + 列式压缩，查询与写入路径分离）。单机实测约 **3.5 万点/秒**。

## 风险

销售如果把集群口径当单机能力承诺，会在验收阶段形成过度承诺。客户只有两台机器时，必须说明测试条件，并引导到配置核算。

## 对客口径（这句可以说）

「10 万点/秒为 3 节点集群压测口径，具体配置以方案书为准。」
