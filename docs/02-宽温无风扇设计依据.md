# 为什么做无风扇宽温，而不是加风扇

## 原理

车间现场粉尘、油雾与振动是风扇故障的高发诱因。产品选择**无风扇被动散热 + 宽温级元器件**，靠结构与外壳散热，把「可动机械件」从整机里拿掉，换取长期免维护。

## 实测数据

- -25℃ / 75℃ 环境箱连续 72 小时通过
- 某汽车零部件集团 12 条产线连续运行 9 个月，无温降告警
- 同工况下带风扇竞品的首年返修率对比数据见内部测试报告

## 设计取舍（必须如实说明）

换取可靠性与可进厂区的代价是：**算力锁定 8 TOPS、不支持内置 5G 模组、不支持外加 GPU 扩展卡**。这不是「后续软件升级能补」的功能，是结构决定的硬边界。客户若要求内置 5G，只能走外置 CPE 方案，不要当场承诺定制。
