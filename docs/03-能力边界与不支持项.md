# 能力边界速查

| 客户常见追问 | 结论 | 替代方案 |
| --- | --- | --- |
| 能不能内置 5G 模组 | **不支持**（结构散热硬约束） | 外置工业 CPE，走有线回传 |
| 能不能加装 GPU | **不支持** | 上位机侧做推理，网关只做采集与归一化 |
| 单机能不能跑满 10 万点/秒 | **不能**，单机约 3.5 万点/秒 | 3 节点集群，或下调采集频率 |
| 能不能公有云 SaaS 交付 | **暂不提供** | 私有化 / 混合云 |
| 能不能热更新配置不停机 | **支持**，v4.2 起 | — |
| 能不能接 Modbus RTU | **支持** | — |

## 销售口径

先回答边界，再给替代方案，**不要当场承诺定制**。判断依据是给你自己看的理由，不是对客户的话术。若客户坚持，记录为需求并走正式评审，不要口头给时间点。
